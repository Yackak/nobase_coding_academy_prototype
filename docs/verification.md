# React 전환 검수 기록

2026-11-04. React + TypeScript + Vite + GSAP 전환과 이미지 모션 구현 검수.

## 빌드

- TypeScript strict 검사와 Vite 브라우저/서버 빌드 통과.
- 빌드 시 전체 한국어 본문을 정적 HTML로 생성하고 브라우저에서 hydrate.
- 캐시된 이미지가 hydration 전에 로딩돼도 complete/naturalWidth 검사로 모션 준비 상태를 복구.
- 최초 SSR 렌더와 클라이언트 렌더가 일치하며 정상 미리보기에서 hydration 오류 없음.
- 이미지 4장 합계 473,924바이트. 원본 PNG는 공개 빌드에서 제외.

## 브라우저

ChatGPT 내장 브라우저에서 실제 페이지를 조작해 확인했다.

- 320·360·390·430·768·1024·1440·1920px: 문서 가로 넘침, 이미지 누락, 주요 제목/학습 장면 내부 넘침 없음.
- PC 3열 과정 카드, 태블릿 좌우형 과정 카드, 모바일 상세 접힘 확인.
- 모바일 중등 과정을 펼치고 상담창을 열면 문의 문구에 ‘중등 내신’ 반영.
- 정상 문의 복사 동작은 성공 안내 표시 확인. 자동화의 clipboard read API가 빈 값을 반환해 OS 클립보드 내용을 별도 확인한 것으로 기록하지 않는다.
- 상담창 브라우저 뒤로가기 시 닫힘 및 본문 잠금 해제.
- 모바일 메뉴에서 Escape로 닫으면 읽던 위치 정확히 복원: 2572.5px → 2572.5px.
- 학습관리 클릭 및 End 키 선택 시 활성 탭, 보고서 제목, 초점이 피드백 단계로 함께 변경.
- 화면 본문과 상담 팝업에 전화번호 숫자 없음.

## 별도 로컬 검수 화면

아래 검수 장치는 임시 빌드 폴더에만 만들었으며 최종 빌드에 포함하지 않았다.

- 모션 감소 matchMedia 응답을 흉내 낸 화면: 펼쳐진 새싹 opacity 1, 접힌 새싹 opacity 0, 재생 버튼 없음. 이는 JS 분기 검수이며 OS 환경설정 실기기 검수와 구분한다.
- 클립보드 실패 화면: PC 전화 버튼은 번호를 표시하지 않고 안내만 제공. 고등 과정 문의 복사 실패 시 직접 선택 가능한 문구에 ‘고등 내신’ 유지.
- 연필 파일을 일시적으로 누락시킨 별도 localhost 화면: 정지 포스터가 표시되고 제목/교육과정 링크 유지. 파일은 즉시 복구.
- 390px에서 렌더된 모든 텍스트의 계산된 글자 크기를 2배로 키운 화면: 문서 가로 넘침 없음, 중등 영어 문장 줄바꿈, 하단 바 높이 약139px에 맞춰 여백 자동 갱신.

## 범위

모바일 전화 연결의 설정과 코드 경로를 확인했으며 실제 전화를 걸지 않았다. 네이버 지도는 기존에 확인된 공식 주소 핀 링크를 그대로 유지한다. iOS/Android 실기기 및 저속 네트워크 속도 측정은 별도 시행하지 않았다. 이미지 실패 대체 동작은 위 방법으로 확인했다.
