# 노베이스 홈페이지 이미지 모션 기획

검토일: 2026-11-04 · 상태: 수정 기획, 이미지 모션은 아직 미구현

## 1. 방향

‘기초에서 자라는 자신감’을 책·새싹·연필의 짧은 움직임으로 보여준다. 현재 정리한 밝은 초록색 화면, 큰 글씨, 간결한 카드 위에 첫 화면의 대표 장면 하나와 학습 내용을 설명하는 작은 연출 두 가지를 더한다.

현재 사이트에는 섹션 등장, 버튼 반응, 메뉴·상담창 전환과 학습관리 내용 전환이 구현되어 있다. 대표 그림 `learning-hero.webp`는 배경·책·잎·연필·그림자가 합쳐진 정지 이미지다. 이미지 속 사물이 독립적으로 움직이려면 분리된 새 소재나 미리 렌더링한 영상이 필요하다.

이번 PC 스타일 정리는 실제 배포 범위이며, 아래 오브젝트 제작과 추가 모션은 후속 구현 범위다.

## 2. 레퍼런스 분석

현재 홈페이지의 화면·미디어 상태를 직접 관찰한 내용과 과거 공식 제작 사례를 구분했다. 시각적으로 비슷해 보인다는 이유로 특정 라이브러리를 사용한다고 추정하지 않았다.

| 레퍼런스 | 확인한 연출 | 우리에게 맞는 해석 |
| --- | --- | --- |
| [토스 현재 홈페이지](https://toss.im/) | 첫 화면의 생활 영상이 재생된다. 스크롤하면 휴대폰의 송금 입력 장면에서 완료 장면으로 진행하며 설명이 함께 나온다. 장면을 크게 유지하면서 사용 과정을 보여주는 구성이다. | ‘책을 펼치고 이해하는 과정’을 한 장면으로 표현한다. 학원 정보 탐색에 필요한 스크롤 길이는 짧게 유지한다. |
| [토스 공식 모션 제작 사례](https://toss.im/tossfeed/article/why-motion-in-finance) | 2022년 글은 동전의 여러 렌더 이미지, 두 가지 날개 자세를 겹치는 방식, 3D 영상과 직접 돌려보는 오브젝트를 설명한다. 현재 홈페이지의 동일 구현을 뜻하지 않는다. | 잎·책·연필을 나누고 시간차를 주면 작은 제작 범위에서도 입체적인 느낌을 낼 수 있다. |
| [Apple MacBook Air](https://www.apple.com/macbook-air/) | 직접 관찰 시 닫힌 두 노트북이 펼쳐진 구도로 바뀌었다. 해당 메인 영상은 약 3.9초에서 정지했고 반복 재생하지 않았다. 큰 제품과 짧은 문구를 중심으로 구성한다. | 첫 방문에 2~3초의 완결된 장면을 보여준 뒤 안정된 이미지로 남긴다. 내용과 상담 버튼은 처음부터 읽을 수 있게 둔다. |
| [Stripe 현재 홈페이지](https://stripe.com/) | 첫 화면의 다채로운 리본 형태가 계속 변하고, 본문에는 결제기·웹 화면·그래프를 겹친 카드가 배치된다. 입체적인 배경과 구체적인 제품 화면이 함께 쓰인다. | 영어 문장과 수학 풀이 카드를 학습 노트 위에 겹쳐, 수업에서 다루는 내용을 보여준다. 노베이스에는 옅은 초록색과 낮은 움직임 강도로 적용한다. |
| [Stripe 지구본 제작기](https://stripe.com/blog/globe) | 2020년 공식 사례는 여러 층의 지구본과 연결선, 스크롤 반응, 화면 밖 재생 중지를 설명한다. 현재 메인 화면의 구현 설명으로 사용하지 않는다. | 진단·계획·복습·피드백의 관계를 연결선과 표시로 설명한다. 움직임이 학습 과정의 의미를 전달하도록 한다. |

공통으로 가져올 점은 오브젝트마다 역할을 주는 것, 문구와 장면을 연결하는 것, 움직임이 끝난 뒤에도 보기 좋은 구도를 남기는 것이다. 노베이스의 방문 목적은 학년·과목·지도 방식·위치 확인과 상담이므로, 긴 화면 고정이나 지속적인 대형 배경 변화는 우선순위에서 제외한다.

## 3. 첫 화면: ‘기초에서 자라는 자신감’

### 최종 구도

- 현재의 크림색 공간과 짙은 초록색 책을 유지한다.
- 펼쳐진 책, 줄기, 좌우 잎, 연필, 얕은 그림자, 영어·수학 요소를 별도 소재로 준비한다.
- 초등 고학년부터 고등학생까지 자연스럽게 받아들일 수 있는 차분한 질감과 비율을 사용한다.
- 제목·설명·교육과정 버튼은 움직이는 그림 밖에 두고 즉시 표시한다.

### 약 2.4초의 장면 구성

| 시간 | 그림의 변화 | 전달할 의미 |
| --- | --- | --- |
| 0.0초 | 완성 구도의 배경과 그림자가 보이며 제목·설명·버튼을 바로 읽을 수 있다. | 방문 즉시 학원의 정보와 다음 행동을 확인 |
| 0.0~0.6초 | 펼쳐진 책이 12~18px 정도 올라오며 가볍게 자리를 잡는다. | 학습의 출발점 |
| 0.4~1.2초 | 줄기와 잎이 차례로 나타나고, 접힌 잎에서 펼친 잎 자세로 바뀐다. | 기초에서 시작하는 성장 |
| 1.0~1.8초 | 연필이 짧게 움직이고 영어 문장 또는 수학식 아래에 밑줄 하나가 그어진다. | 이해하고 직접 풀어보는 학습 |
| 1.6~2.4초 | 영어·수학 요소가 제 위치에 놓이고 모두 정지한다. | 정돈된 학습과 자신감 |

수치는 노베이스를 위한 초안이며 토스·Apple의 수치를 복제한 것이 아니다. 실제 소재에 적용해 속도와 이동 폭을 조정한다. 레이어 방식에서는 자연스러운 책장 휘어짐이나 잎의 생물학적 성장을 약속하지 않는다. 그 정도의 변형이 필요하면 영상 제작 방식으로 전환한다.

PC에서는 포인터를 따라 그림 전체에 최대 2도 정도의 깊이감을 주는 효과를 선택적으로 검토한다. 입력을 방해하거나 글자를 움직이지 않으며, 기본 구현의 필수 조건으로 두지 않는다. 터치 환경은 처음 등장하는 짧은 장면으로 충분하다.

## 4. 교육과정: 작은 학습 장면

세 카드에 같은 애니메이션을 반복하기보다 학년별 학습 목표를 짧은 도식으로 보여준다. 현재 정리한 카드의 제목·목표·상세 내용 순서는 유지한다.

| 과정 | 작은 장면 | 실행 조건 |
| --- | --- | --- |
| 초등 고학년 | 영어 단어가 짧은 문장으로 정렬되고, 수학의 기본 개념 조각이 맞춰진다. | 카드가 처음 보일 때 1회, 약 1.2초 |
| 중등 내신 | 교과 문장에 밑줄이 그어지고 한 단원의 복습 표시가 완성된다. | 카드가 처음 보일 때 1회, 약 1.2초 |
| 고등 내신 | 수학식의 풀이 단계가 차례로 나타나고 마지막 확인 표시가 붙는다. | 카드가 처음 보일 때 1회, 약 1.2초 |

사용하는 문장·수식은 실제로 맞는 간단한 예제로 검수한다. 점수 상승, 합격률, 실제 학생 성과처럼 해석될 수 있는 숫자는 넣지 않는다. 모바일에서는 카드 본문의 길이를 늘리지 않도록 상세 펼치기 안 또는 작은 높이의 그림 영역에 배치한다.

## 5. 학습관리: 선택에 반응하는 노트

현재의 4단계 버튼과 학습관리 예시를 기반으로 확장한다.

1. 현재 수준 확인: 영어·수학 항목에 진단 표시가 붙는다.
2. 학습 계획: 필요한 학습 항목이 정리되고 순서가 표시된다.
3. 수업과 복습: 밑줄과 풀이 확인 표시가 차례로 나타난다.
4. 내신 점검과 피드백: 확인한 항목이 다음 목표로 연결된다.

단계 변경은 사용자의 클릭·키보드 조작에 반응한다. 노트 자체의 위치는 유지하고 바뀐 부분만 0.4~0.7초 안에 표현한다. 자동으로 단계를 넘기지 않는다. ‘학습관리 예시’ 표시와 실제 학생 기록이 아니라는 설명은 계속 보이게 한다.

## 6. 제작 방식 선택

| 방식 | 필요한 작업 | 적합성 |
| --- | --- | --- |
| **분리된 이미지 4~6장 + 웹 애니메이션** | 배경, 책, 줄기·잎, 연필, 그림자 등을 움직일 수 있게 제작. 잎 자세는 필요 시 2개 준비. | **권장 1차안.** 기존 부드러운 입체 그림의 톤을 이어가며 부분 움직임을 제어하기 쉽다. |
| 짧은 3D 렌더 영상 + 정지 이미지 | 자연스러운 책장 변형·잎 성장·조명 변화까지 하나의 영상으로 제작. PC·모바일 구도와 포스터 준비. | 대표 장면의 시각적 완성도를 더 높이는 후속안. 영상 품질과 다운로드 크기를 함께 관리해야 한다. |
| 실시간 3D | 모델·재질·조명·카메라·렌더링 로직과 기기별 검증. | 직접 회전하거나 탐색하는 기능이 필요해질 때 검토. 현재 학원 소개의 우선 구현에는 포함하지 않는다. |

현재 평면 이미지에서 보이는 부분만 잘라 움직이면 뒤에 가려진 부분과 그림자가 비어 보일 수 있다. 원본의 분위기를 참고해 배경과 소재를 분리 제작해야 한다. 참고 기업의 이미지·영상은 복제하거나 사이트 자산으로 사용하지 않는다.

## 7. 구현·검수 기준

- 첫 화면에는 가벼운 정지 이미지를 먼저 보여준다. 추가 모션 파일 때문에 제목이나 상담 기능의 표시를 기다리게 하지 않는다.
- 위치·회전·크기·투명도 중심으로 움직임을 구성한다. 화면 밖 또는 탭이 숨겨진 상태에서는 진행을 멈춘다. [웹 애니메이션 성능 가이드](https://web.dev/articles/animations-and-performance/)
- `prefers-reduced-motion`에서는 완성된 정지 장면을 표시한다. 모션 재생 여부와 관계없이 모든 정보와 기능을 이용할 수 있게 한다.
- 기본은 짧은 1회 재생이다. 다시 재생하기를 제공하고, 향후 자동 반복을 채택한다면 정지 기능을 추가한다. 필수적이지 않은 자동 움직임이 5초를 넘고 다른 콘텐츠와 함께 표시되는 경우 정지·일시정지·숨김 수단을 제공한다. [W3C 기준](https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide)
- 터치 스크롤을 가로채지 않는다. PC 포인터 효과를 모바일의 기울기 센서 권한 요청으로 대체하지 않는다.
- 320·360·390·430px 모바일, 768px 태블릿, 1024·1440·1920px PC와 200% 글자 확대에서 구도와 잘림을 확인한다. 저속 연결·이미지 로딩 실패에는 정지 이미지나 정돈된 배경으로 남긴다.
- 추가 다운로드 크기는 1차안에서 합계 약 500KB 이내를 목표로 시작하되, 제작 후 실제 화질·속도를 측정해 결정한다. 현재 달성한 측정값을 뜻하지 않는다.

## 8. 적용 순서

1. **대표 장면 소재 제작:** 한 장의 최종 구도를 확정하고 레이어를 제작한다.
2. **첫 화면 모션 구현:** 2.4초 장면, 다시 재생, 정지 이미지 대체, 모바일 구도를 검수한다.
3. **학습관리 연출 확장:** 기존 단계 선택에 노트 표시와 연결 동작을 추가한다.
4. **교육과정 장면 추가:** 대표 장면과 같은 질감으로 작은 학습 도식을 제작한다.
5. **선택 효과 검토:** PC 포인터 깊이감 또는 짧은 고품질 영상은 앞 단계 결과를 보고 판단한다.

첫 화면과 학습관리부터 적용하면 가장 적은 장면 수로 브랜드의 인상과 학습 방식의 이해를 함께 개선할 수 있다.
