# 노베이스 홈페이지 이미지 모션 구현 기록

업데이트: 2026-11-04 · 상태: React 기반 이미지 모션 구현 완료

## 1. 적용 결과

‘기초에서 자라는 자신감’을 책·새싹·연필의 독립된 움직임으로 구현했다. 밝은 초록색 화면과 읽기 편한 글씨를 유지하면서 대표 장면, 학년별 학습 도식, 선택에 반응하는 학습관리 노트를 추가했다.

선택한 방식은 **투명 이미지 레이어 + React·GSAP 애니메이션**이다. 기존 한 장의 `learning-hero.webp`는 초기 표시와 소재 로딩 실패 시 대체 이미지로 사용한다. 자연스러운 책장 변형을 위한 영상이나 실시간 3D 모델은 사용하지 않았다. 이 문서의 구현 상태는 소스 기준이며, 배포 완료 여부와 기기별 검수 결과는 배포·검수 기록에서 별도로 확인한다.

## 2. 레퍼런스 분석

현재 홈페이지의 화면·미디어 상태를 직접 관찰한 내용과 과거 공식 제작 사례를 구분했다. 시각적으로 비슷해 보인다는 이유로 특정 라이브러리를 사용한다고 추정하지 않았다.

| 레퍼런스 | 확인한 연출 | 우리에게 맞는 해석 |
| --- | --- | --- |
| [토스 현재 홈페이지](https://toss.im/) | 첫 화면의 생활 영상이 재생된다. 스크롤하면 휴대폰의 송금 입력 장면에서 완료 장면으로 진행하며 설명이 함께 나온다. 장면을 크게 유지하면서 사용 과정을 보여주는 구성이다. | ‘책을 펼치고 이해하는 과정’을 한 장면으로 표현한다. 학원 정보 탐색에 필요한 스크롤 길이는 짧게 유지한다. |
| [토스 공식 모션 제작 사례](https://toss.im/tossfeed/article/why-motion-in-finance) | 2022년 글은 동전의 여러 렌더 이미지, 두 가지 날개 자세를 겹치는 방식, 3D 영상과 직접 돌려보는 오브젝트를 설명한다. 현재 홈페이지의 동일 구현을 뜻하지 않는다. | 잎·책·연필을 나누고 시간차를 주면 작은 제작 범위에서도 입체적인 느낌을 낼 수 있다. |
| [Apple MacBook Air](https://www.apple.com/macbook-air/) | 직접 관찰 시 닫힌 두 노트북이 펼쳐진 구도로 바뀌었다. 해당 메인 영상은 약 3.9초에서 정지했고 반복 재생하지 않았다. 큰 제품과 짧은 문구를 중심으로 구성한다. | 첫 방문에 2~3초의 완결된 장면을 보여준 뒤 안정된 이미지로 남긴다. 내용과 상담 버튼은 처음부터 읽을 수 있게 둔다. |
| [Stripe 현재 홈페이지](https://stripe.com/) | 첫 화면의 다채로운 리본 형태가 계속 변하고, 본문에는 결제기·웹 화면·그래프를 겹친 카드가 배치된다. 입체적인 배경과 구체적인 제품 화면이 함께 쓰인다. | 영어 문장과 수학 풀이 카드를 학습 노트 위에 겹쳐, 수업에서 다루는 내용을 보여준다. 노베이스에는 옅은 초록색과 낮은 움직임 강도로 적용한다. |
| [Stripe 지구본 제작기](https://stripe.com/blog/globe) | 2020년 공식 사례는 여러 층의 지구본과 연결선, 스크롤 반응, 화면 밖 재생 중지를 설명한다. 현재 메인 화면의 구현 설명으로 사용하지 않는다. | 진단·계획·복습·피드백의 관계를 연결선과 표시로 설명한다. 움직임이 학습 과정의 의미를 전달하도록 한다. |

공통으로 가져올 점은 오브젝트마다 역할을 주는 것, 문구와 장면을 연결하는 것, 움직임이 끝난 뒤에도 보기 좋은 구도를 남기는 것이다. 노베이스의 방문 목적은 학년·과목·지도 방식·위치 확인과 상담이므로, 긴 화면 고정이나 지속적인 대형 배경 변화는 우선순위에서 제외한다.

## 3. 제작한 소재

기존 대표 그림의 초록색 책·아이보리 종이·노란 연필 질감을 참고해 built-in `image_gen`으로 새 소재를 제작했다. 투명도를 보존한 손실 없는 WebP 4개의 합계는 **473,924바이트(약 463KiB)**다. 라이브러리·기존 이미지·글꼴을 포함한 전체 페이지 용량을 뜻하지 않는다.

| 공개 파일 | 크기 | 용량 | 역할 |
| --- | --- | ---: | --- |
| `public/assets/motion/book.webp` | 960×960 | 310,088바이트 | 짙은 초록 표지와 아이보리 페이지의 펼친 책 |
| `public/assets/motion/sprout-closed.webp` | 560×560 | 44,446바이트 | 잎이 모인 새싹의 시작 자세 |
| `public/assets/motion/sprout.webp` | 560×560 | 72,090바이트 | 두 잎이 펼쳐진 새싹의 완성 자세 |
| `public/assets/motion/pencil.webp` | 560×560 | 47,300바이트 | 좌하단 심에서 우상단 지우개로 놓인 연필 |

새싹 두 자세는 줄기 끝의 위치를 맞춰 겹쳐 전환한다. 줄기와 각각의 잎을 별도 모델로 움직이는 방식이 아니다. 원본 PNG는 `source-assets/motion/`에 보관하며 공개 폴더에는 최적화한 WebP만 둔다. 전체 생성 프롬프트, 원본 경로, 크기와 변환 정보는 [`asset-provenance-motion.json`](../asset-provenance-motion.json)에 기록했다.

## 4. 첫 화면의 완결된 장면

`HeroScene`에서 소재가 모두 준비되고 장면이 화면에 보일 때 약 2.4초의 연출을 1회 재생한다. 제목·설명·교육과정 버튼은 그림 밖에 있어 재생을 기다리지 않는다.

| 순서 | 구현된 변화 |
| --- | --- |
| 0.0~0.6초 | 책이 16px 올라오며 작은 기울기를 정돈한다. |
| 0.35~1.15초 | 새싹이 올라오고, 모인 잎 자세에서 펼친 자세로 교차 전환한다. |
| 1.0~1.8초 | 연필이 제자리를 잡고 영어 문장의 밑줄이 그어진다. |
| 1.6~2.4초 | 영어·수학 카드가 순서대로 나타난 뒤 완성 구도에서 멈춘다. |

재생 중에는 **잠시 멈춤**, 일시정지 후에는 **이어서 보기**, 종료 후에는 **다시 보기**를 제공한다. 화면 밖으로 나가거나 브라우저 탭이 숨겨지면 진행을 멈추며, 사용자가 직접 멈춘 상태는 유지한다. 정밀 포인터가 있는 PC에서는 그림만 최대 약 2도 반응하며, 터치 스크롤이나 기울기 센서를 사용하지 않는다.

`prefers-reduced-motion`에서는 완성된 정지 구도를 표시하고 재생·포인터 효과를 끈다. 소재 로딩에 실패하면 기존 대표 그림을 유지한다.

## 5. 교육과정과 학습관리

`CourseScene`은 실제 텍스트와 도형으로 학년별 짧은 학습 예시를 보여준다. 처음 화면에 들어올 때 약 1.2초 재생하고 완성 상태로 남는다.

| 과정 | 구현한 장면 |
| --- | --- |
| 초등 고학년 | `I can learn.` 문장 조각이 정렬되고 `½ + ¼ = ¾` 분수 예시가 나타난다. |
| 중등 내신 | `Practice makes progress.`의 핵심에 밑줄이 그어지고 개념·복습·확인 표시가 완성된다. |
| 고등 내신 | `2x + 4 = 10 → 2x = 6 → x = 3` 풀이와 확인 표시가 순서대로 나타난다. |

각 장면에는 ‘학습 예시’ 표시와 보조 기술용 설명을 제공한다. 점수 상승이나 실제 학생 성과를 표현하는 숫자는 사용하지 않았다.

`LearningSystem`은 사용자가 4단계를 선택할 때 연결선·현재 단계 표시·확인 표시·밑줄·설명을 짧게 전환한다. 자동으로 다음 단계로 넘어가지 않으며 클릭과 방향키·Home·End 조작을 지원한다. ‘학습관리 예시’ 표시와 실제 학생의 기록이 아니라는 설명을 유지한다.

교육과정·학습관리 모션도 화면 밖 또는 숨겨진 탭에서 멈추고, 움직임 감소 설정에서는 완성된 내용으로 표시한다. 노트에 키보드 초점이 들어오면 장면을 완성 상태로 전환해 읽기를 방해하지 않는다.

## 6. 유지·검수 기준

- 소재 크기나 재생 시간을 변경해도 첫 화면의 문구와 상담 기능을 지연시키지 않는다.
- 위치·회전·크기·투명도를 중심으로 구성하고, 화면 밖 재생 중지와 정지 이미지 대체를 유지한다. [웹 애니메이션 성능 가이드](https://web.dev/articles/animations-and-performance/)
- 기본은 짧은 1회 재생이다. 향후 필수적이지 않은 자동 움직임이 5초를 넘고 다른 콘텐츠와 함께 표시되면 정지·일시정지·숨김 수단을 제공한다. [W3C 기준](https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide)
- 320·360·390·430px 모바일, 768px 태블릿, 1024·1440·1920px PC와 200% 글자 확대에서 구도·잘림·상담 버튼 접근을 확인한다.
- 다시 보기·잠시 멈춤·화면 이탈 후 복귀·탭 전환·움직임 감소 설정·소재 로딩 실패를 함께 확인한다. 이 목록은 후속 변경 때도 유지할 검수 기준이며 실기기 검증 완료를 주장하는 목록이 아니다.
- 참고 기업의 이미지·영상은 사이트 자산으로 사용하지 않는다. 영상이나 실시간 3D는 현재 구현에 추가해야 하는 미완료 항목이 아니라 별도의 제작 방식이다.
