# 노베이스 학원 웹사이트

정읍 상동 노베이스 학원의 반응형 소개 페이지입니다. 영어·수학, 초등 고학년 기초부터 중·고등 내신 집중관리까지 안내합니다.

- [홈페이지](https://yackak.github.io/nobase_coding_academy_prototype/)
- [소스 저장소](https://github.com/Yackak/nobase_coding_academy_prototype)
- React + TypeScript + Vite + GSAP. 데이터베이스나 별도 서버 없이 GitHub Pages에서 공개합니다.

## 실행과 배포

Node 24를 사용합니다.

```sh
npm ci
npm run dev
```

개발 주소는 터미널에 표시되는 `/nobase_coding_academy_prototype/` 경로입니다.

```sh
npm run build
npm run preview
```

빌드는 타입 검사 → 브라우저 번들 → 서버 렌더 → 정적 HTML 생성 순서입니다. 본문을 HTML에 미리 포함하고 React가 상호작용을 이어받으므로 첫 화면의 글과 기본 그림은 JavaScript 실행을 기다리지 않습니다. 외부 서버를 실행하는 SSR 서비스는 아닙니다.

`main`에 소스를 올리면 GitHub Actions가 `npm ci`와 빌드를 실행하고 `dist/`를 자동 배포합니다. `dist/`는 생성 결과이며 직접 수정하거나 커밋하지 않습니다. 저장소의 Pages 설정은 GitHub Actions를 유지합니다.

## 적용한 모션

[레퍼런스 분석과 구현 기록](docs/image-motion-plan.md)에 토스·Apple·Stripe의 관찰 내용과 적용 판단을 정리했습니다.

- 첫 화면: 분리된 책이 자리 잡고, 접힌 새싹이 펼쳐지고, 연필·밑줄·학습 카드가 순차적으로 나타나는 약 2.4초 장면입니다. 1회 재생 후 멈추며 일시정지·이어서 보기·다시 보기를 제공합니다.
- PC: 마우스 위치에 따라 그림에 최대 2도의 깊이감을 줍니다. 글과 상담 버튼은 움직이지 않습니다.
- 교육과정: 초등은 영어 단어와 분수 개념, 중등은 문장 밑줄과 복습 체크, 고등은 수학 풀이 단계 예시를 보여줍니다. 모바일에서는 상세 펼치기 안에 있습니다.
- 학습관리: 네 단계 선택에 따라 연결선·체크·밑줄과 노트가 바뀝니다. 방향키/Home/End를 지원하며 자동으로 단계를 넘기지 않습니다.
- 화면 밖과 숨겨진 탭에서는 모션을 멈춥니다. 모션 감소 설정에서는 완성된 정지 장면을 보여줍니다. 이미지 로딩 실패에는 기존 정지 그림을 유지합니다.
- 섹션의 짧은 등장 효과, 버튼 누름 반응, 메뉴·상담창 전환도 유지합니다. 스크롤을 강제로 고정하거나 반복 배경을 재생하지 않습니다.

모션 WebP 4장은 합계 **473,924바이트**입니다. 생성 원본은 `source-assets/motion/`에 보관하며 배포에 포함하지 않습니다. 이미지 생성 기록은 `asset-provenance-motion.json`과 `asset-provenance.json`에 있습니다.

## 상담과 운영 정보

전화번호는 페이지·팝업·검색 설명에 숫자로 표시하지 않습니다. 모바일에서는 전화 앱 연결, PC에서는 번호 복사를 제공합니다. 복사 실패에도 번호를 화면에 노출하지 않습니다. 문의 문구와 주소 복사 실패에는 직접 선택할 수 있는 영역을 제공합니다. 과정별 상담은 선택한 과정을 문의 문구에 반영합니다.

카카오톡 링크는 미확정 상태입니다. 준비 중 버튼은 전화 상담과 문의 예시 안내를 엽니다. 수강료·정원·일정은 임의로 넣지 않고 상담 시 안내합니다. 학습관리 자료와 모션 도식은 예시이며 실제 학생 기록이나 성과가 아닙니다.

모바일 메뉴와 상담창은 읽던 위치를 보존하고, Escape·뒤로가기·닫기를 지원합니다. 메뉴는 배경의 스크롤과 초점을 제한합니다. 하단 상담 바는 메뉴·상담창이 열리면 숨깁니다.

주소는 전라북도 정읍시 상동 74-1 2층이며, 도로명은 전북특별자치도 정읍시 학산로 103-18, 2층입니다. 네이버 지도는 확인된 주소 핀의 공식 공유 링크를 사용합니다. 공유용 프로토타입의 `noindex, nofollow` 설정을 유지합니다.

- 책·새싹·연필: 내장 이미지 생성 도구로 제작한 브랜드 일러스트. 실제 학원이나 학생 사진이 아닙니다.

- Pretendard: 자체 호스팅, SIL Open Font License. `public/assets/Pretendard-LICENSE.txt` 포함.
