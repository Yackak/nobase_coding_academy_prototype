# 노베이스 학원 웹사이트

정읍 상동 노베이스 학원의 반응형 소개 페이지입니다. 영어·수학을 지도하며, 초등 고학년과 중·고등학생 내신 집중관리를 안내합니다.

- 홈페이지: https://yackak.github.io/nobase_coding_academy_prototype
- 접근 범위: 링크로 누구나 열람 가능 (GitHub Pages)
- 실행: 프로젝트 폴더에서 `python3 -m http.server 4173 --directory dist`
- 별도 설치나 빌드 없이 `dist` 폴더를 정적 호스팅할 수 있습니다.

## GitHub Pages 배포

`main` 브랜치에 변경 사항을 올리면 `.github/workflows/pages.yml`에서 `dist/`만 자동 배포합니다. GitHub 저장소의 Actions 탭에서 배포 상태를 확인할 수 있습니다. 별도의 서버, 데이터베이스, 유료 호스팅은 사용하지 않습니다.

- 소스 저장소: https://github.com/Yackak/nobase_coding_academy_prototype
- Pages 설정: GitHub Actions
- 기본 주소: https://yackak.github.io/nobase_coding_academy_prototype/

## 포함된 화면과 동작

학원 소개, 초등 고학년·중등 내신·고등 내신 과정, 영어·수학 학습관리 예시, 수강 안내, FAQ, 실제 전화 상담, 네이버 지도 위치, 모바일 메뉴와 하단 상담 바를 구현했습니다. 학습관리 탭은 방향키/Home/End로 이동할 수 있으며, 상담 팝업은 Escape로 닫힙니다. 과정별 상담 버튼은 선택한 과정을 문의 문구에 반영합니다. 문의 문구 복사에 실패하면 직접 복사할 수 있는 입력 영역을 표시합니다.

## 운영 정보 수정

`dist/site-config.js`에서 상담 링크, 전화, 주소, 지도 링크, 상담 시간, 교육 대상, 수업 일정과 수강료를 변경합니다. 학원 설명과 상세 과정 원고는 `dist/index.html`, 기본 디자인은 `dist/styles.css`, 모바일 디자인은 `dist/mobile.css`, PC·태블릿 디자인은 `dist/desktop.css`, 모션 설정은 `dist/motion.css`, 인터랙션은 `dist/app.js`에서 수정합니다.

## 모바일 화면과 모션

PC 화면도 모바일과 같은 밝은 초록색 배경·카드·읽기 편한 글자 크기로 정리했습니다. 1024px 이상에서는 과정 3개를 나란히 비교하고, 768–1023px에서는 과정 설명과 세부 내용을 좌우로 배치합니다. 학습관리 예시는 기울기와 메모 장식을 제거한 반듯한 카드이며, 상담 기능·지도·전화번호 숨김 방식은 유지합니다.

오브젝트 내부가 움직이는 후속 이미지 모션은 [레퍼런스 분석과 수정 기획](docs/image-motion-plan.md)에 정리했습니다. 이 문서의 책·새싹·연필 연출은 기획 상태이며 아직 실제 사이트에 구현하지 않았습니다.

767px 이하에서는 본문 16px, 보조 문구 13–14px, 좌우 여백 20px를 기준으로 읽는 흐름을 정리했습니다. 과정 카드는 학년·과목과 목표를 먼저 보여주고 상세 내용을 펼칠 수 있습니다. 학습관리 단계는 세로 카드로 제공하며 선택한 단계의 예시로 이동할 수 있습니다. 상담은 하단 고정 바에 모으고, 메뉴·상담창이 열리면 바를 숨깁니다. 전화번호는 계속 텍스트로 노출하지 않습니다.

전체 화면 메뉴는 배경 스크롤과 초점을 제한합니다. 닫기·Escape·뒤로가기로 읽던 위치를 복원하며, 메뉴의 항목을 선택하면 해당 제목으로 이동합니다. FAQ는 모바일에서 접힌 상태로 시작하고 여러 답변을 동시에 열 수 있습니다. PC에서는 과정 상세가 모두 펼쳐집니다.

참고한 공식 자료와 적용 판단:

- [토스 — 인터랙션, 꼭 넣어야 해요?](https://toss.tech/article/interaction): 누름 피드백, 상태 변화 전달, 일관된 모션이라는 원칙을 버튼·메뉴·학습관리 예시에 적용했습니다.
- [토스 — Value first, Cost later](https://toss.tech/article/21023): 학습 대상과 과정의 내용을 먼저 읽고 상담을 선택하도록, 모바일 첫 화면은 교육과정 탐색을 중심으로 정리했습니다.
- [토스 — Simplicity 4 제작기](https://toss.tech/article/simplicity_behind): 모바일에서 읽는 길이와 화면 순서를 우선하는 접근을 참고했습니다.
- [Apple HIG — Motion](https://developer.apple.com/design/human-interface-guidelines/motion): 짧고 목적이 분명한 전환, 취소 가능한 동작, 움직임을 줄이는 설정을 반영했습니다.

180ms 누름 반응, 280ms 메뉴·상담창 등장, 230ms 학습관리 예시 전환, 520ms 최초 섹션 등장과 `cubic-bezier(.22,1,.36,1)`은 노베이스에 맞춰 선택한 값이며 원본 서비스의 공식 모션 수치를 복제한 것이 아닙니다. 첫 화면과 하단 상담 버튼은 지연 없이 표시합니다. 반복 부유 효과나 스크롤 강제 전환은 없으며, `prefers-reduced-motion`에서는 모션을 끕니다. 본문은 기본적으로 표시돼 있어 애니메이션 지원 여부에 관계없이 읽을 수 있습니다.

확인된 운영 정보는 다음과 같습니다.

- 과목: 영어·수학
- 모집 대상: 초등 고학년, 중고 내신 집중관리
- 전화: 010-2438-0080
- 주소: 전라북도 정읍시 상동 74-1 2층
- 네이버 지도: https://naver.me/5bClL0tf (네이버 지도에서 해당 지번의 위치 공유 링크 확인)
- 도로명: 전북특별자치도 정읍시 학산로 103-18, 2층
- 카카오톡 상담 링크: 추후 업데이트 (`kakaoUrl: null`)

휴대폰에서는 전화 앱 연결을 시도하며, PC에서는 번호를 복사합니다. 실제 통화는 사이트 검증 중 실행하지 않습니다. 전화번호는 본문·팝업·검색 설명에 텍스트로 표시하지 않고 전화 상담 버튼으로 제공합니다. 카카오톡 준비 중 버튼은 전화 상담 버튼과 문의 예시가 있는 안내를 엽니다. 수강료·정원·시간표·상담시간의 임의 예시는 제거했으며, 확정 전에는 상담 시 안내합니다. 학생 기록은 학습관리 예시로 표시합니다.

추후 변경 시에는 다음을 확인합니다.

1. `kakaoUrl`에 실제 상담 공유 링크를 넣고, 페이지의 “카카오톡 준비 중” 및 추후 업데이트 안내를 상담 가능 문구로 바꿉니다.
2. 수업 일정과 수강료가 확정되면 설정 파일과 HTML의 기본 안내를 함께 반영합니다.
3. 전화·주소 변경 시 HTML의 기본 표시 및 도로명도 함께 확인합니다. 지도 링크는 실제 위치로 검증한 값을 사용합니다.
4. 도메인 변경 시 OG URL/이미지 URL과 sitemap 주소도 수정합니다. 현재 `noindex, nofollow`는 공유용 사이트의 검색 노출을 제한하기 위해 유지합니다.

## 검증

PC 톤 정리 후에는 768·1024·1280·1440·1920px와 390px 모바일을 다시 확인했습니다. 가로 넘침과 이미지 누락이 없고, 화면 폭에 따른 과정 카드 재배치·학습관리 전환·상담 팝업 표시와 전화번호 숨김이 유지됩니다. 브라우저 오류 로그 없음. 새 오브젝트 모션 기획의 검수 기준은 후속 구현 시 적용합니다.

320, 360, 390, 430, 768, 1024, 1440px에서 가로 넘침과 이미지 누락이 없음을 브라우저로 확인했습니다. 667×375 가로 화면에서는 긴 메뉴를 내부 스크롤할 수 있습니다. 모바일 메뉴의 앵커 이동·초점, 메뉴의 Escape/뒤로가기와 상담창 뒤로가기 후 위치 복원, 과정 펼치기와 선택한 과정의 상담 문구, 학습관리 전환을 확인했습니다. JavaScript 구문 검사와 HTML 참조 검사를 통과했고 검수 중 브라우저 오류 로그가 없었습니다. iOS/Android 실기기와 실제 전화 통화는 미검증입니다. 전화 연결 설정, PC 번호 복사와 주소 복사, 카카오톡 준비 안내, 네이버 지도의 실제 주소 핀은 기존 검증을 유지합니다.
